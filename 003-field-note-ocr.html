Google AI Studio（無料）で発行したGemini APIキーを貼り付けてください。 ？
・取得手順：Google AI Studio（aistudio.google.com）にGoogleアカウントでログイン→「Get API key」→「Create API key」で発行できます。
・キーは「AIza」から始まる文字列です。コピーしてこの欄に貼り付けてください。
・無料枠の範囲で利用できますが、Google側の利用規約・レート制限に従います。1回の読み取りごとにこのツールから直接Gemini APIへ送信され、本ツール・サーバー側には保存されません。
・キー漏洩防止のため、他人と共有のPC・画面共有中の入力は避けてください。

文字がはっきり写るよう、明るい場所で野帳ページに正対して撮影してください。手書き文字が不鮮明な場合、読み取り結果に「[?]」が付くことがあります。 ？
・対応形式：JPEG・PNG等、スマホ/PCカメラで撮影した一般的な画像形式。
・影や反射があると誤読の原因になります。できるだけ平らに開き、真上から撮影してください。
・表形式（野帳の罫線）がある場合、AIは行・列の構造を維持しようとしますが、罫線が多い・数値が密集していると崩れることがあります。
・読み取り結果は必ず原本と照合してください。特に数値（距離・角度等）の誤読は測量結果に影響するため、目視チェックを省略しないでください。
